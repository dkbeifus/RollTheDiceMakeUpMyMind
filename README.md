# Roll The Dice And Make Up My Mind

## Purpose
  This project for CMPA-4303-D02 is a website for making random decisions.  The page contains an editable list from which a random choice will be randomly picked at the click of the button.  Dice are not really involved, but the name portrays the intent to make random choices.  

  This project was started as a way to alleviate the inevitable  back and forth conversation of “I don’t care either, where do you want to eat?”.   This website provides a means to make a list of options and supply a random pick.  The idea stemmed from choosing a restaurant, but it is intentionally generic enough allow for any type of list so more than one random decision can be made.

## Tools and Technologies
  Visual Studio Code was used for the code editor because it runs on Linux and I have been using it regularly with satisfactory results for the past five years.  To test the updates, the Firefox browser is used since it is my default choice in browsers for the past twenty years, but I also started to use Chrome as a second check since the majority of browsers use Chromium in the background.  I also discovered a function I use does not work in Firefox and I handle it through a conditional statement so Firefox and Chrome performs slightly different actions.  The repository is GitHub, so I also use GitHub Desktop for change control because it does a good job giving a visual representation of what I am doing with the commits and pushes.  The live site is hosted on Cloudflare since I use them for my DNS and because it appeared to be very straight forward and not convoluted about what is available with the free tier.  
 No AI assistants have been used for this project other than the basic search engine summaries.  This is a deliberate choice to ensure I get the necessary hands-on experience for which I can use to evaluate AI code writing effectiveness on future projects.
